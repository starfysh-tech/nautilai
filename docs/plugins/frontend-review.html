frontend-review

Audit React components and Tailwind tokens for architecture and design-token health.

Install

/plugin install frontend-review@nautilai

What it does

Two read-only audits for a React + Tailwind frontend analyze component architecture and design-token health. The react-component-architecture skill flags oversized components, prop drilling, and duplicated UI patterns that should be extracted to primitives; the tailwind-design-token-validator detects arbitrary values, dynamic class concatenation, invalid @apply use, and hardcoded colors. Both auto-detect the frontend source root and Tailwind config without assuming hardcoded paths, cite every finding with file:line, and run a bundled Python analysis engine (python3 3.10+); the Tailwind config analyzer uses node when present to resolve the config, falling back to regex parsing.

Commands / skills

  • /react-component-architecture

    Audit component architecture for oversized components, prop drilling, duplicated UI patterns, and folder organization issues.

    explicit slash form only
  • /tailwind-design-token-validator

    Audit Tailwind usage for arbitrary values, dynamic class concatenation, @apply overuse, inline styles, and design-token violations.

    explicit slash form only

How it works

Both audits auto-detect the frontend root and configuration, then scan and report findings with file:line citations.

1locate React root
2scan components
3scan Tailwind
4report findings
Under the hood
  • /react-component-architecture — detects oversized components, prop drilling, duplicated UI patterns, folder organization issues; runs a bundled Python engine, with Glob/Grep/Read confirming findings (no hardcoded paths) (disposition: report).
  • /tailwind-design-token-validator — detects arbitrary values, dynamic class concatenation, invalid @apply use, inline styles, design-token violations; runs a bundled Python engine with optional Edit for auto-fixed token swaps (dispositions: auto-fix for 1:1 token maps, report for findings, ask-user for approximate changes).
  • Auto-detection: locates React package.json for source root; discovers tailwind.config.* or v4 CSS @theme as source of truth for tokens.
  • Invocation: both skills are user-invoked only (not auto-firing) and read-heavy, using per-project shoals to carry forward team corrections across runs.
  • Shoals: .claude/shoals/frontend-review.<skill>.md — project corrections (thresholds, token mappings, patterns to ignore).

action-first

Shape every response around one doable-now action instead of a buried lede — lead with the step, number and cap the rest, restate progress each turn.

Install

/plugin install action-first@nautilai

What it does

A persistent output-style skill, not a one-shot generator. Once invoked it reshapes every response for the rest of the session: the first line is a command, path, or step rather than context; multi-step work is numbered and capped at five items; progress restates every turn instead of assuming the reader remembers where things stood; time estimates land in concrete units; preamble, recap, and sign-off phrasing are cut entirely.

The shape yields to the task when the two conflict — an "explain this" request still gets a full explanation, a destructive action still gets a confirmation, a debug spiral still gets a diagnostic question instead of another blind retry. The rules govern form, not what gets said.

Commands / skills

  • /action-first

    Turn on action-first output shaping for the rest of the session. Stays on until you say "stop action-first" or "normal mode".

    explicit slash form only

How it works

Every response runs through the same shape before it's sent: lead with the action, structure any multi-step work, restate where things stand, then strip the framing that doesn't survive the pre-send check.

1lead with actioncommand / path / step
2number & cap stepsmax 5
3restate progress
4pre-send strippreamble / recap / hedges
Under the hood
  • Ten rules govern shape: lead with the action, number and cap multi-step work at five items, end with one concrete next step, defer tangents to a one-line offer at the end, restate progress every turn (using the harness's task/plan tool when one exists), give time estimates in concrete units, surface completed work before anything else, state errors as cause-and-fix with no alarm language, cap any list at five, and cut preamble/recap/sign-off entirely.
  • Five override conditions take priority over the shape: an explicit "explain" or "walk me through" request, a destructive action needing confirmation, a debug spiral (three-plus turns of "still broken"), real ambiguity worth one clarifying question, and a rule that would delete the answer itself (e.g. "what are my options" keeps 2–4 ranked options rather than being forced to one path).
  • Inside an agent harness, the system prompt outranks the skill: tool-call announcements the harness requires still happen, routine steps get done rather than asked-permission-for, and time estimates point at whoever executes the step.
  • A five-point pre-send check runs before every reply: drop an opening sentence that announces intent, drop a closing "anything else?", drop "by the way" asides, drop hedges that carry no real uncertainty, replace idioms with the literal action.

cc-skill-audit

Review your skills against Anthropic's authoring guidance and find trigger, structure, and security issues.

Install

/plugin install cc-skill-audit@nautilai

What it does

Reviews SKILL.md files against Anthropic's official skill-authoring guidance, reporting findings by severity. Audits frontmatter validity and trigger reliability (testing descriptions with multiple prompt phrasings to catch under- and over-triggering), body structure and conciseness, bundled resource organization, portability across Claude Code and other surfaces, and security (hardcoded credentials, credentials in logs, undeclared network access). Sweep mode also runs a scored, ranked pass — Haiku scores every installed skill, Sonnet fact-checks each score against disk, and a final agent ranks the set worst-to-best into a written scorecard.

How it works

1fetch guidance
2discover skills
3test triggers

5report findings
Under the hood
  • Fetches Anthropic's live skill guidance from code.claude.com/docs at runtime, so it won't fail a skill on a rule that's since changed.
  • Sweep mode discovers user, project, and installed-plugin skills, then runs a scored Workflow: a Haiku worker scores each SKILL.md on clarity, frontmatter validity, and trigger quality; a Sonnet fact-checker verifies every factual claim against the skill's actual files on disk; a final agent ranks the full set worst-to-best with cross-set patterns into skill-audit-report.md.
  • Falls back to batched Task fan-out (~5 skills per haiku subagent) when the Workflow tool is unavailable — subagents score against the same rubric, the parent fact-checks their claims against disk, then ranks and writes the same report, marked as self-reported scores without independent verification.
  • Runs in an isolated fork context.
  • Tests description field for triggering reliability by drafting direct/implicit/alternative phrasings.
  • Validates frontmatter (required fields, name/description validity).
  • Checks body structure, portability across surfaces, and bundled resources.
  • Scans for hardcoded credentials, undeclared network access, and commercial deps disguised as open source.
  • Reports findings by severity: Blocker, High, Medium.

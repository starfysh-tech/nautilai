cc-validate-hooks

Validate your hooks configuration — catch schema errors, invalid events, and malformed matchers.

Install

/plugin install cc-validate-hooks@nautilai

What it does

Validates the hooks block in your project settings.json and settings.local.json and user settings.json files. Parses JSON, checks event names against the known Claude Code hook event list, validates matcher shapes and regex, and verifies each hook's type, command, and timeout fields. With --fix, it repairs simple issues in place and writes a backup.

Commands / skills

  • /cc-validate-hooks

    Validate your hooks configuration and report errors.

    "check my hooks", "why isn't my hook firing", "validate settings.json", "hooks broken"
  • /cc-validate-hooks --fix

    Auto-correct repairable issues and write a backup.

    same triggers as above, with "fix"

How it works

1parse settings.json
2validate hooks
3check matchers
4report or --fix
Under the hood
  • Reads the project settings.json, project settings.local.json, and user settings.json files.
  • Parses JSON syntax and validates the hook structure (event → matchers → hooks).
  • Checks event names against the known Claude Code hook event list (warns on unrecognized).
  • Compiles matcher regex patterns to catch malformed expressions.
  • Validates each hook's type, command, and timeout fields.
  • With --fix, corrects unused matchers and missing type defaults, writing a backup.
  • Error and warning counts are reported via __ERRORS__/__WARNINGS__ sentinel lines rather than the process exit code, so the shell wrapper can tell "ran, found errors" apart from "crashed".
  • Runs as a forked skill on Haiku, since hook validation is mechanical and doesn't need a larger model.

Requirements

python3 (or python) on your PATH.

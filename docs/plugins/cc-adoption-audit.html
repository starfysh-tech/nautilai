cc-adoption-audit

Compare your Claude Code setup to available features and find what you should adopt next.

Install

/plugin install cc-adoption-audit@nautilai

What it does

Reads your Claude Code configuration, installed plugins and skills, and project stack, then anchors on the official docs to map what you could be using but aren't. Reports three threads: adoption opportunities ranked by fit and payoff, configuration gaps worth closing, and features shipped in the last ~30 days you haven't picked up yet.

Commands / skills

  • /cc-adoption-audit

    Runs a prioritized adoption audit of your setup.

    explicit slash form only

How it works

1fetch docs
2inspect setup
3compare features
4output report
Under the hood
  • Fetches the official Claude Code docs index (always fresh, never stale).
  • Inspects your setup: settings, hooks, installed plugins, skills, MCP servers, and project stack; from ~/.claude.json it extracts only the mcpServers key rather than reading the whole file.
  • Checks your Claude Code version against the latest release.
  • The available-features and current-setup steps run independently and can each delegate to a haiku subagent that returns a distilled, source-cited inventory.
  • Cross-references what you have against what's available, then prioritizes by relevance and impact.
  • Reports three threads: adoption opportunities, configuration gaps, and features shipped in the last ~30 days.

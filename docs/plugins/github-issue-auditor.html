github-issue-auditor

Audit GitHub issues for duplicates, orphaned sub-issues, unlabeled items, and label inconsistencies.

Install

/plugin install github-issue-auditor@nautilai

What it does

The skill audits a GitHub repository's open issues via read-only inspection for cleanup opportunities. It detects fuzzy-matched duplicate titles using normalized Levenshtein similarity (default threshold 0.75, customizable), orphaned sub-issues whose parent issues are closed, unlabeled or stale items (default 30 days, customizable), and labels inconsistent with the repo's own auto-detected taxonomy. It reports findings-first with issue numbers and evidence (age, similarity score), then stops at a review checkpoint. Any mutations — closing duplicates, relabeling, or commenting — execute only after explicit user approval via a gated task list, with changes recorded under the user's GitHub account.

How it works

The skill reads issues, detects the repo's label taxonomy, audits for cleanup opportunities, and stops at a review checkpoint before applying any mutations.

1list issues
2detect label taxonomy
3audit all categories
4report findings
5approve mutations
Under the hood
  • /github-issue-auditor — single skill that reads via GitHub CLI (gh) or GitHub MCP server (whichever available); read-only by default (audit is report); any mutation (close/relabel/comment) is ask-user behind an approval gate. Audits for marked duplicates, fuzzy-matched duplicates (Levenshtein similarity, default 0.75), orphaned sub-issues, unlabeled items, stale issues (default 30 days), and label inconsistencies.
  • Auto-detection: lists repo labels and groups them by inferred category (status/type/priority/area); does not assume label names. The analyzer accepts a detected-taxonomy label map for unlabeled-item suggestions instead of hardcoding label names.
  • Discovery fetches the open-issue list once and reuses it across categories rather than re-querying per category.
  • Reporting: findings-first, prioritized list omits clean categories; evidence (issue numbers, age, similarity %) grounds every claim.
  • Customizable flags: --similarity 0.XX (duplicate threshold), --stale-days N (age threshold).
  • Shoals: .claude/shoals/github-issue-auditor.github-issue-auditor.md — project corrections (e.g. "issues labeled keep-open are never stale").

Requirements

GitHub CLI (gh) authenticated via gh auth status, or the GitHub MCP server configured. The skill will use whichever is available and fails loudly if neither is present.

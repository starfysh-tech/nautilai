wireframe

Create low-fidelity wireframes — ASCII layouts, wiremd interactive prototypes, or Mermaid diagrams for UI planning.

Install

/plugin install wireframe@nautilai

What it does

The skill generates low-fidelity wireframes in three formats. ASCII mode (the default) produces text boxes, forms, and layout annotations for quick iteration with zero dependencies. Wiremd mode uses Markdown-ish syntax that renders to clickable HTML or exports as React components via the separate wiremd CLI. Mermaid mode generates user-flow and screen-state diagrams — flowcharts, state machines, sequence diagrams — that render inline in GitHub, VS Code, and the Mermaid Live Editor. An optional stdlib-only script can extract real component names from a React directory, enabling reference-based wireframing without inventing placeholder names.

Commands / skills

  • /wireframe

    Create a low-fidelity wireframe. Defaults to ASCII text layout; request wiremd prototype or Mermaid diagram to switch modes.

    explicit slash form only

How it works

The skill detects the requested mode from natural language, optionally extracts real component names, then generates the wireframe in the chosen format.

1parse request
2detect mode
3extract components
4generate wireframe
Under the hood
  • /wireframe — single skill that detects mode (ASCII, wiremd, Mermaid) from request text; defaults to ASCII (no dependencies); pauses for review before expanding a flow or exporting.
  • scripts/extract_components.py — optional stdlib-only script to list React/TSX components from a given directory; fails open if directory absent or unreadable; requires python3 on the PATH.
  • --update-reference injects the catalog into a project-local .claude/wireframe-catalog.md (created if absent, never the plugin install dir, since the install cache is wiped on update); a later run reads that file alongside the bundled reference even without re-extracting.
  • Modes: ASCII (text-based, zero deps), wiremd (Markdown-ish syntax, requires separate wiremd CLI for HTML/React export), Mermaid (user-flow/screen-state diagrams — flowcharts, state machines, sequence diagrams — renders inline in GitHub/VS Code).
  • Reference: skills/wireframe/references/reference.md documents syntax cheat sheets for each mode.
  • Generative skill: no finding dispositions or shoals (not applicable to one-shot wireframing).

Requirements

ASCII and Mermaid modes have no required dependencies. For component extraction, python3 on your PATH is optional but enables listing real component names. To render wiremd prototypes to HTML or React, the third-party wiremd CLI is optional and not bundled. To preview Mermaid diagrams as ASCII in the terminal, node plus the third-party beautiful-mermaid package is optional and not bundled. All three degrade gracefully if absent.

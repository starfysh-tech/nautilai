Investigates in parallel: a reuse and reduction scan for redundant steps, then dependency tracing, breaking-change risk, error-handling gaps, and architecture — each grounded in code. How it works

The skill extracts the plan's goal, proposed changes, touched files, dependencies, and assumptions. It investigates in parallel: a reuse and reduction scan identifies existing code or patterns that make planned steps redundant, then dependency tracing, breaking-change risk, error-handling gaps, and architecture analysis — each finding grounded in file:line.

A simplification pass runs first (reuse, delete, configure, YAGNI, smallest-diff), then risk and edge-case questions, reconciling the two so risks get the cheapest correct fix rather than piling on defensive code. The skill revises the plan in place to the leanest correct version and adds one "Assumptions to validate before implementing" gate.

Works out of the box with built-in agents (Plan, code-reviewer, Explore). Optionally uses specialists from feature-dev, pr-review-toolkit, or Codex plugins if installed — graceful degradation, no hard fails.

Shoals: records corrections in .claude/shoals/review-plan.review-plan.md for the next run, preventing repeated mistakes on the same project.

2reuse scan
3dependency + risk analysis
4simplification pass
5reconcile risks
6revise + gate
Under the hood
  • Built-in agents: Plan (architecture), code-reviewer (quality), Explore (code search).
  • Optional specialists: feature-dev:code-explorer, pr-review-toolkit agents (silent-failure-hunter, type-design-analyzer, pr-test-analyzer), Codex (GPT cross-model review).
  • Shoals file: .claude/shoals/review-plan.review-plan.md — learns from user corrections on the same project.
  • Output: verdict (CRITICAL / CAUTION / REASONABLE), footprint (LEAN / ACCEPTABLE / OVER-ENGINEERED), what changed, code you can avoid writing.
  • Before editing, ensures the change is recoverable: an untracked plan file (or one outside a git repo) gets a .bak copy first; a tracked file relies on git history.

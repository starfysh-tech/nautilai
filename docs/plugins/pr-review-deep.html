pr-review-deep

Structural code-quality review of a branch or PR — finds whole branches, layers, and modes to delete, not just rearrange.

Install

Claude Code

/plugin install pr-review-deep@nautilai

Hermes Agent

$ hermes skills install skills-sh/starfysh-tech/nautilai/pr-review-deep

No tap needed in Hermes — hermes skills tap add does not index this repo. Hermes has no MCP tools, so PR fetching uses gh; reviewing a local branch diff needs no gh at all.

What it does

Focuses on implementation quality, maintainability, abstraction design, type/boundary contracts, and behavior-preserving structural simplification. Identifies high-leverage restructurings with cited evidence and proposes them for your decision. Does not perform edits or expand PR scope — all findings are raised for review.

How it works

The skill reads the diff from the current branch or a PR, citing every finding with file:line and verifying claims against the code before raising them. It focuses on implementation quality, maintainability, type/boundary contracts, and behavior-preserving structural simplifications — identifying high-leverage restructurings, not just local cleanups.

The review reads the diff via a graceful degradation chain: GitHub MCP (preferred), then gh CLI, then plain git diff. All findings are categorized by severity (Blocking, Should-fix, Suggestion) and proposed for your decision — the skill never edits code or expands the PR's scope.

Shoals: reads and appends user corrections to .claude/shoals/pr-review-deep.pr-review-deep.md in your project.

Under the hood
  • Diff read chain: GitHub MCP (preferred) → gh CLI → git diff, degrading loudly on failure.
  • Finding severity: Blocking, Should-fix, Suggestion.
  • Dispositions (per nautilai conventions): all findings are report (proposes, never auto-fixes); user-actionable proposals are ask-user (never self-resolved).
  • Evidence-first: every finding cites file:line, verified against the code before raised; behavior-preservation is treated as a hypothesis until proven.
  • Findings are proposed, not performed — describes restructurings concretely and leaves the decision to the author; never edits code or expands the PR's scope.
  • Shoals file: .claude/shoals/pr-review-deep.pr-review-deep.md — records corrections to prevent repeated mistakes.
